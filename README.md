# Agent Skills Library

A centralised collection of reusable AI agent skills, workflows, and resources for Google Cloud, data engineering, DevOps, agentic AI, MCP, and automation.

Designed to work with Antigravity today and other AI coding agents in the future.

## Repository Structure

```text
agent-skills-library/
├── skills/       # Reusable agent skills
├── agents/       # Tool-specific configurations
├── scripts/      # Installation and automation scripts
├── templates/    # Templates for creating new skills
├── docs/         # Documentation and guides
└── README.md
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/vikramshinde12/agent-skills-library.git
cd agent-skills-library
```

## Using Skills

1. Browse the `skills/` directory.
2. Select the skill you need.
3. Follow the installation instructions for your AI agent.
4. Use or customise the skill in your project.

## Keeping Skills Updated

Pull the latest changes:

```bash
git pull
```

## Adding a New Skill

1. Create a new directory under the appropriate category in `skills/`.
2. Add a `SKILL.md` file containing the skill instructions.
3. Include any supporting documentation, scripts, or examples.
4. Commit and push your changes.

## Supported Tools

- Antigravity
- Claude Code
- OpenAI Codex
- Other compatible AI agents

Compatibility depends on each tool's skill format and discovery mechanism.
